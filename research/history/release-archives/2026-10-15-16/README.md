# Historical release archives: 15–16 October 2026

This directory preserves the dated publication, reference, arXiv-source and formalized-research bundles produced before the unified 18 October 2026 release.

These files are retained for provenance and byte-level reproducibility. They are not the active submission artifacts. The authoritative current manuscript and reproducibility files are in [`submission/current/`](../../../../submission/current/).

The archive-local `SHA256SUMS.txt`, `build_report.json`, `research_build_report.json` and build evidence belong to the historical release process. Its two index entries for `research_build_report.json` and `research_bundle.sha256` were refreshed on 18 October 2026; the historical reports, bundles and PDFs were not changed. The root `SHA256SUMS.txt` also covers every file in this directory.

The 15 October snapshots correspond to the earlier 34-page/16-reference publication package. The 16 October snapshots are later historical builds. Neither replaces the current 37-page/20-reference unified manuscript.
