# 数学结果与文献关系

## 精确常数的意义

对有界交换序列和零和权重，本文将最优 Hoeffding 系数确定为总体规模的精确函数。奇偶差异可以由两个常数直接表达：

\[
D_N=\sup_{X,a}\frac{\operatorname{Var}\langle a,X\rangle}{\|a\|_2^2}
=\frac{4\lfloor N^2/4\rfloor}{N(N-1)}.
\]

偶数总体满足 \(C_N^\star=D_N\)。奇数总体满足

\[
D_N=\frac{N+1}{N}<C_N^\star<\frac{N}{N-1},\qquad
C_N^\star-D_N=\frac{2}{3N^2}+O(N^{-3}).
\]

取均匀近均衡 Hamming slice 上的 \(X\)，对比量 \(X_1-\bar X_N\) 在奇数总体的 \(\lambda=\log((N+1)/(N-1))\) 处取得最优指数界等号。偶数总体的同一构造在零倾斜极限确定最佳常数。

## 高阶极值结果的范围

Atouani–Marchal–Arbel 的一般驻点刻画和三点公式提供最优代理的基础工具；其 Remark 3.6 中的局部展开以倾斜参数趋零为变量。本文的高阶定理以有限总体参数 \(N^{-1}\) 为变量，在全局最优倾斜处展开超几何最优代理：

- 对任意固定样本量 \(m\) 和固定奇数失衡 \(s\)，证明全局最优点的唯一性、解析性及三阶展开。
- 将最优规范化代理展开至 \(N^{-4}\)，给出 \(O_{m,s}(N^{-5})\) 余项。
- 对固定 \(m\) 同时比较全部成功数 \(k\)，确定充分大奇数总体中的两个最接近平衡的极值成功数。
- 给出每个有限总体平衡点附近的精确二阶失衡系数。

单次、两次抽样展开分别与 Bernoulli 公式及三点专门化一致。对固定 \(m\ge2\)，与单次抽样的距离为

\[
L_N-R_{N,1,m}=\frac{2(m-1)}{3N^3}
+\frac{2(m-1)(2m+1)}{3N^4}+O_m(N^{-5}).
\]

因此样本量之间的首次分离出现在三阶，四阶系数进一步量化这一距离。
